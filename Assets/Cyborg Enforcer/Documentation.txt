Thank you for purchasing the Cyborg Enforcer. In this package you should find:

- max file folder: Containing a 2013.max file of the character with a Catrig.
	If you want to animate the character and use these animation in unity, 
	don't forget to not export the controllers.

- Model folder : Containing the game ready meshes of the Cyborg and a gun. 
	There is 2 version of the caracter for the avatars, one which should 
	work with almost every animation (Char_Cyborg_MESH) the other for custom 
	animation made with the cat rig (Char_Cyborg_MESH(catrig1))

- Prefab folder : Contaning both character prefab.If you want to use your custom animation from 
	the max file or any other Catrig animation use Char_Cyborg(catrig)_prefab, otherwise always 
	use Char_Cyborg_prefab.

- Scene folder: Containing a Scene with both prefab in it.

- Shader folder: Containing A parabole custom shader, fun with metallic surfaces.

- Textures folder: Containing all textures for the character.

- Turnaround Cyborg Demo folder: A mishmash folder with asset for the demo scene. 
	It also include the demo scene.
